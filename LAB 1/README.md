### Objective

The objective of this practical is to get started with Node.js by verifying the Node.js and npm installation, creating and initializing a Node.js project, writing and executing a Node.js program, working with variables and data types, and understanding the difference between Browser JavaScript and Node.js.

### Brief Description of the Practical

In this practical, the Node.js environment was verified and a basic Node.js project was created. Since Node.js was already installed on the system, its installation was verified using the `node -v` and `npm -v` commands.

The Node.js project was initialized using npm, which created the `package.json` file. A program was created in `app.js` to display student information and different messages using `console.log()`.

Variables were created for student details and different JavaScript data types were explored using the `typeof` operator. The difference between Browser JavaScript and Node.js was also documented in a text file named `difference.txt`.
